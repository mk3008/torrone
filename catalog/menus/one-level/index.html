MENU-001 / Navigation menu / research example

One-level expandable navigation with selected-row accent

A parent opens or closes a single level of child menu items. The parent is not a selectable destination. Only the selected child or standalone leaf receives a filled row and left accent stripe. This pattern concerns menu contents, not the surrounding drawer's visibility.

What this design means

Observe and preserve when applicable

  • One layer of children below a parent; the sample does not define multiple nested levels.
  • The parent has an expand/collapse affordance but never the active destination's fill or left stripe.
  • Selected leaves are visible through row fill, leading accent and text emphasis; the same model applies to child and standalone items.
  • Parent expansion does not change the current destination, and hover is not selection.

Choose per application

  • Real menu labels, routes, authorization and whether navigation search is offered.
  • Keyboard and focus policies, narrow layouts and assistive-technology behavior.
  • Whether menu content appears in a drawer, compact rail or another Shell.
  • Color palette, exact pixel dimensions, animations, DOM and framework.
Separate pattern: SHELL-001 controls hiding the entire drawer via the header. MENU-001 describes the hierarchy and selection feedback inside a visible navigation area. The two can be used independently.

Original source and limits

Unchanged captures from the historical PoC 017 browser Reference and research plan. Images are copied as complete 1440 × 900 PNGs; CSS crops only their display to the left menu. Open any image for its full original. This preserves individual source images if the catalog layout changes.

Research screenshots are not a design-quality approval or a guarantee of real-device, accessible or native-platform behavior. The parent may appear gray during pointer hover, but only leaf selection receives the distinctive filled row and left accent.

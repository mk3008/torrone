MENU-002 / Header user menu / research example

Header account popover with Escape focus return

A user control in the application header opens a small account popover. Escape closes the popover and returns focus to the originating control. This design responsibility is different from the left navigation tree.

Web-originOpen + EscapeHistorical example · not approved as a new Reference

Menu states

Two independent 1440 × 900 source screenshots

Design intent

What the images communicate

  • The account trigger belongs to the persistent header, not the content work area.
  • Opening reveals a compact, anchored menu with identity and actions.
  • Escape dismisses the menu and the trigger remains the keyboard focus target.

What the product decides

  • Whether and how the user identity is shown; account and authentication capabilities.
  • The menu command set and consequences, including sign-out behavior.
  • Focus trapping, pointer dismissal, narrow/mobile presentation and accessibility coverage.
  • Platform-native menu components, exact dimensions, borders and colors.
Not the drawer navigation: see MENU-001 for parent/child menu rows and selected-destination treatment, and SHELL-001 for drawer visibility.

Source and limits

The source captures are from PoC 017 and its historical browser evidence. A CSS-only crop displays the top-right region without changing the independent image files; links below each tile open the full screenshot.

These are bounded observed states, not proof of real authentication, successful sign-out, assistive technology support or deployment readiness. No new design approval is implied.

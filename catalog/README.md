# Torrone visual catalog (pilot)

Browse the [catalog index](index.html) and the first entry, [SHELL-001 — Header-controlled, fully hideable left drawer](shells/workspace/index.html).

This is an **image-first discovery surface**, not a new approval registry, specification language, component runtime or UI-testing system. Every state is a separate PNG; the HTML page only determines the layout and captions.

For a new system, inspect the picture and its brief explanation, verify the intended platform and the entry's evidence level, then adapt it to the product's Business Design. Do not infer unpictured interaction behavior.

Approved executable design originals remain under [curated References](../references/README.md); historical experiments are unchanged. The current shell entry is research-selected but not approved as a new catalog design.

A catalog ID such as `SHELL-001` identifies one design pattern independently of its display name, directory slug, and gallery order. The name describes the differentiating interaction: this pattern hides the drawer completely using a header control. A drawer that leaves an icon-only navigation rail visible would be a different pattern, not another state of this one. The ID is not an approval status.

Additional categories (screens, components, topology) can be added when real examples are ready. No empty folders or custom indexing tool are required.

## Menu pattern

[MENU-001](menus/one-level/index.html) collects one-level expandable menu states. Its parent expands and collapses, while current-selection styling belongs only to leaf destinations. MENU-001 describes the navigation content; SHELL-001 describes drawer visibility. Neither approval nor a universal application policy is implied.

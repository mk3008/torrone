Draft scope, keyboard behavior & review notes

Try the complete operation

Select 業務設計, choose either Read marked “Normally omitted”, then select 実装. Check that the temporary line disappears, the Detail matches the new selection, and Input-only / Exception remain present. Compare All lines, clear, and reselect.

Candidate interaction choices

Tab / Shift+Tab traverse controls; Enter or Space activates nodes and relation lines. “View details” moves to the Detail heading. Choosing a relation from Detail moves focus to its new heading; “Back to node” restores the originating relation button. Escape or Clear selection clears selection and temporary lines. Mode changes clear selection while focus stays on the radio. Blank graph space also clears selection. These are reversible proposals, not an approved application-wide keyboard policy.

Preserve / May vary

Preserve independent kind and scope meaning, selectable outside-scope nodes, full relation captions, matching graph / Detail selection, and temporary Read disclosure that resets when the target changes. Business Exception is a business handoff, not a UI failure. Coordinates, sizes, DOM, framework and routing are implementation choices.

Boundaries

One static layout, four nodes and six unmodified relations from the Viewer fixture. Japanese fixture text is retained. No arbitrary import, editing, pan / zoom, automatic layout, large-graph performance or whole-Viewer coverage. Narrow layout is a reachability check, not mobile-device or assistive-technology verification. No external requests or saved data.

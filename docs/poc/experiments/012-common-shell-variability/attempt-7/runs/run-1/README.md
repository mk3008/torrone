# Run 1 common shell

Standalone static HTML/CSS/JS implementation of the requested common Header, Drawer, and neutral scrolling workspace.

Open `index.html` directly in a browser. Initial states are available with:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The Drawer controller, theme controller, parent disclosure, and local Drawer search operate entirely in the browser. No external resources are used.

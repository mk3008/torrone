# Run 2 — Common shell specimen

Standalone static HTML/CSS/JS specimen for the supplied common-shell prompt.

Open `index.html` in a browser. Query parameters establish initial state:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The Header buttons update the corresponding URL parameter locally. Drawer search filters only the fixed navigation fixture, and the main workspace contains the requested neutral sequence only.

No external images, fonts, CDN assets, or scripts are used.

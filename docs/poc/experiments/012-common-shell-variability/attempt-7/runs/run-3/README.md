# Run 3 common shell

Standalone static HTML/CSS/JS implementation of the supplied common-shell fixture.

Open `index.html` in a browser. Query parameters set initial state:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The Header controls update the visible state and query parameters. The Drawer search filters only the supplied fixed navigation fixture.

There are no external runtime, image, font, CDN, or script dependencies.

# Flows

- [List/Card to detail](list-to-detail.md) - When an available record-opening role should connect a grid or card collection and detail pattern.
- [Record lifecycle](record-lifecycle.md) - Connect read, create, edit, and delete tasks without treating them as one configurable screen.
- [Screen transition](screen-transition.md) - Preserve task context and distinguish navigation from mutation across screens.
- [Wizard progress](wizard-progress.md) - Move through a stable linear task, review it, and complete it.

Flows own cross-screen decision criteria. Screen patterns own only their provided and required transition roles; product bindings own feature availability, destinations, permissions, and state.

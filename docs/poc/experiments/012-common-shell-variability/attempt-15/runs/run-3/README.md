Static local implementation from the supplied Attempt 15 inputs.

Leaf activation replaces the binding current destination and moves exactly one visual and semantic (`aria-current="page"`) current-item treatment. The parent toggles only expanded state. Current destination persists across collapse and re-expansion. Empty search has no X button or reserved space. No external dependency is used.

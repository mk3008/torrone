# Run 3 common shell

Standalone static implementation of the supplied common-shell fixture.

Open `index.html` in a browser. Initial state can be selected with:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The Header controls update the URL state locally. Drawer search filters only the supplied fixture and preserves the parent context for matching children.

No external dependencies are used.

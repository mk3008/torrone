# Run 1 common shell

Standalone static HTML/CSS/JS specimen for the supplied common-shell fixture.

Open `index.html` directly in a browser. Supported initial-state queries are:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The header controls toggle Drawer visibility and the next theme. The Drawer
search filters only the supplied fixture and keeps the parent visible when a
matching child is shown.

# Common-shell sample — run 3

Open `index.html` in a browser.

Initial state query parameters:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The fixture demonstrates an independently scrolling Header/Drawer/workspace shell, navigation filtering and disclosure, current-destination movement without route changes, and a two-mode palette. It uses only local HTML, CSS, and JavaScript.

# Run 3 common shell

Standalone local static implementation from the supplied fixed prompt and Manifest.

Open `index.html` and use `?drawer=open` or `?drawer=hidden`, together with `?theme=light` or `?theme=dark`, to set the initial state. Header controls update the state and query string.

The Drawer search filters only the fixed fixture. Its X clear button is created only after text is entered; it is absent and reserves no space while the query is empty. All icons are local inline SVG equivalents of the supplied vocabulary. No external dependencies are used.

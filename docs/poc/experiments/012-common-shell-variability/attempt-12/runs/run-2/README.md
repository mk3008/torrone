# Run 2 — Common shell

Open `index.html` locally. Initial state accepts `?drawer=open` / `?drawer=hidden` and `?theme=light` / `?theme=dark`.

The current navigation location is a product-binding input. This fixture binds it initially to `項目 01-01` for comparison only; the component does not have a fixed default item. A selected child keeps the same label indentation as unselected child siblings, while its selection surface and indicator begin at the Drawer’s physical left edge.

No external images, fonts, CDN resources, or scripts are used.

# Run 3 common shell

Standalone static implementation from the supplied Attempt 12 Manifest and fixed prompt.

Open `index.html` with `?drawer=open` or `?drawer=hidden`, plus `?theme=light` or `?theme=dark`, to set initial state.

The current destination is binding input. This comparison fixture supplies `項目 01-01`; it is explicitly not a component default that always selects that item. A selected child retains the same indented label start as child siblings, while its full selection surface and accent begin at the Drawer’s physical left edge.

The clear X is only created for a nonempty query. All icons are local SVG and there are no external dependencies.

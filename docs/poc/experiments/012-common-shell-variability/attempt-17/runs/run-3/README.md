# Run 3 common shell

Standalone static implementation from Attempt 17 consumer inputs. The local visible-Drawer icon is a complete panel, leading divider, and left-facing chevron; the hidden state uses the same complete panel with a right-facing chevron. All strokes sit inside the 24×24 SVG canvas.

Search, current destination, disclosure, independent scroll regions, and query-driven Drawer/theme state are included. No external dependency is used.

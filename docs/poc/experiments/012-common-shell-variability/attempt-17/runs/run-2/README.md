# Run 2 — Common shell

Open `index.html` locally. `?drawer=open` / `?drawer=hidden` and `?theme=light` / `?theme=dark` choose initial shell state.

The local Drawer control uses a complete panel, a leading divider, and a directional chevron fully inside the SVG canvas. Current destination, disclosure, search, theme and independent scroll behavior are local; no external assets are used.

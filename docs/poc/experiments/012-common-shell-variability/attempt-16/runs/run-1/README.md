# Run 1 common shell

Local static Header, Drawer, and neutral scroll workspace. The Drawer controller uses local canonical-equivalent PanelLeftClose (complete panel, left pane, left chevron) when visible and PanelLeftOpen (same panel, right chevron) when hidden.

The local binding supplies one current destination and the disclosure state is independent. The search, scroll regions, theme switch, and query initial states run without any external dependency.

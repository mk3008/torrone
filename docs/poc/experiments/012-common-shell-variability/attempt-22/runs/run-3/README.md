# Common shell variability sample

Open `index.html` in a browser. The sample has no external dependencies.

- `?drawer=open` or `?drawer=hidden` selects the initial Drawer state.
- `?theme=light` or `?theme=dark` selects the initial theme.

The Drawer search, disclosure, current-destination binding treatment, Drawer toggle, and theme toggle are interactive. Navigation fixtures update the current binding in place; they do not navigate to business screens.

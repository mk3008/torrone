# Common shell variability sample

Open `index.html` in a browser. The sample has no external dependencies.

- `?drawer=open` or `?drawer=hidden` selects the initial Drawer state.
- `?theme=light` or `?theme=dark` selects the initial palette.

The Header controls update the visible state and the query string. The fixed Drawer fixture supports filtering, clearing a search, group disclosure, and in-place current-destination selection. The workspace deliberately contains only its required title and numbers 1 through 80 for independent scrolling checks.

# Common shell sample

Open `index.html` in a browser. It has no external dependencies.

- `?drawer=open` or `?drawer=hidden` selects the initial Drawer state.
- `?theme=light` or `?theme=dark` selects the initial theme.

The Header remains fixed while the Drawer navigation and workspace have independent vertical scroll areas. The navigation search filters the supplied fixed fixture, keeps matching children under their parent, and provides a clear action only for a nonempty query.

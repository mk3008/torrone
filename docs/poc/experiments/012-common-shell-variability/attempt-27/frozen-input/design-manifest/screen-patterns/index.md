# Screen patterns

- [Search with grid](record-list.md) - Support searching, dense scanning, and opening a record while keeping list context.
- [Search with cards](search-with-cards.md) - Support searching and browsing individually identifiable records.
- [Record detail](record-detail.md) - Read one record without presenting disabled edit controls.
- [Record create](record-create.md) - Collect values for one new record and create it explicitly.
- [Record edit](record-edit.md) - Change an existing record while preserving identity and current values.
- [Record delete](record-delete.md) - Confirm deletion as a bounded destructive task.
- [Wizard](wizard.md) - Complete a stable linear task over three or more meaningful steps.
- [Dashboard](dashboard.md) - Support monitoring, triage, and navigation from current operational information.

# Common shell variability — run 2

Self-contained static implementation of the supplied common-shell fixture.

Open `index.html` in a browser. Initial states may be selected with:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The Drawer search filters only the fixed navigation fixture, retains the parent context for matching children, and exposes a clear action and no-match state. The Header remains outside the independently scrolling Drawer and workspace regions.

There are no external images, fonts, scripts, stylesheets, or dependencies.

# Common shell variability — run 1

Self-contained static specimen for the supplied common-shell prompt.

Open `index.html` in a browser. Initial states are selectable with query parameters:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The Header remains fixed while the workspace scrolls. The Drawer navigation list has its own vertical scroll region; its search filters the supplied fixed fixture immediately, retains matching child parent context, provides clearing, and reports no matches.

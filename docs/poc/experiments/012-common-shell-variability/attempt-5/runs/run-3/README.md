# Run 3 — Common shell specimen

Open `index.html` in a modern browser.

Initial-state query parameters:

- `?drawer=open` or `?drawer=hidden`
- `?theme=light` or `?theme=dark`

The header remains fixed in the shell while the workspace scrolls. The Drawer
has its own scrolling menu list and offers immediate fixed-fixture filtering.
No external assets or dependencies are used.

# Run 1 common shell

Standalone local HTML/CSS/JS implementation of the requested Header, Drawer, and neutral scrolling workspace. Open `index.html` locally. Query state accepts `?drawer=open`, `?drawer=hidden`, `?theme=light`, and `?theme=dark`.

The fixture binding initially supplies `item-01-01` as the current destination. Selecting a supplied Drawer item updates only that local binding value and moves the current-item treatment; it does not create a screen transition.

All SVG icons and interactions are local. No external assets, fonts, CDN, or scripts are used.

# Run 2 — Common shell

Open `index.html` locally. Initial state accepts `?drawer=open` / `?drawer=hidden` and `?theme=light` / `?theme=dark`.

The initial current destination is the fixture binding `項目 01-01`, not a component default. Selecting any supplied navigation item updates only this local binding and transfers the current-item treatment; no screen transition is created.

No external images, fonts, CDN resources, or scripts are used.

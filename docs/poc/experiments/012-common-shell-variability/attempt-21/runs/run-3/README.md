# Common shell variability specimen — run 3

Open `index.html` locally. The specimen implements the supplied fixed shell fixture:

- Header with a Drawer controller and an icon-only Light/Dark mode command.
- Drawer search, clear, parent disclosure, current-destination binding, and independently scrolling navigation.
- A neutral, independently scrolling workspace containing only the supplied heading and numbers 1 through 80.

Initial URL state is supported with `?drawer=open` or `?drawer=hidden` and `?theme=light` or `?theme=dark`. The controls update those two URL parameters without navigation.

There are no external fonts, images, scripts, stylesheets, or network dependencies.

# Run 2 — Common shell

Open `index.html` locally. `?drawer=open` / `?drawer=hidden` and `?theme=light` / `?theme=dark` select initial state.

`binding.currentDestination` is the fixture state. Leaf activation updates that single value and moves one selection only; parent disclosure changes only expanded state. A collapsed selected child remains the binding value and regains its selection when expanded. No external images, fonts, CDN resources, or scripts are used.

# Run 3: common shell

This is a standalone static HTML, CSS, and JavaScript implementation of the supplied common-shell fixture.

Open `index.html` in a browser. Use `?drawer=open` or `?drawer=hidden`, and `?theme=light` or `?theme=dark`, to set either initial state. The Header controls update the running state and URL query.

The menu search filters only the fixed Drawer fixture. Its clear control is created only when the query has a value, so an empty search field has neither the control nor reserved trailing space.

No external image, font, CDN, script, or other runtime dependency is used.

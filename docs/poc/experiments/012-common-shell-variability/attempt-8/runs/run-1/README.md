# Run 1: common shell

This is a standalone local static implementation of the requested Header, Drawer, and neutral scrolling workspace.

Open `index.html` in a browser. Initial shell states may be selected with `?drawer=open`, `?drawer=hidden`, `?theme=light`, and `?theme=dark`.

The Drawer controller, theme controller, Drawer disclosure, and Drawer-local fixture search work without a server or external dependency.

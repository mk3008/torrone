# Product-owned input freeze

Attempt 1 is excluded from stability evidence because it stopped before input
consumption. Attempt 2 keeps two authorities separate:

| Authority | Owner | Contents |
| --- | --- | --- |
| Approved Reference and Manifest | reusable design | visual/semantic relationships and reusable guidance |
| Product input | application team | labels, menu content/order, allowed product states, fixture content, non-goals, and harness selection |

The product contract deliberately does not prescribe positioning, sizing,
visual hierarchy, Drawer layout, or a copyable visual recipe. See the blob
inventory, portable preflight, and canary record before dispatching any Run.

# Experimental cold-start knowledge supplement

When an experiment claims Consumer style-implementation independence, different
file hashes, class names, local IDs, or the absence of imports are not sufficient
proof. Inspect whether the Consumer's CSS and source organization are
independently structured rather than a systematic renaming of Reference rules.
The Consumer may reproduce required observed values, but should not derive its
source organization from the Reference. Record the proof method without turning
source similarity into an unproven permanent numeric threshold.

# Experimental Human Calibration replay supplement

Treat a human reviewer's suggested alternative as a hypothesis, not as accepted
design authority. Prefer the smallest change that resolves the explicit
observation without inventing extra modes, completion actions, or surrounding
workflow. When more than one product-coherent model remains and the feedback
does not select one, report the design choice as unresolved rather than claim
that Conformance or comparative validation reproduced the human-approved
model.

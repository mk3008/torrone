# `aria-activedescendant` relational observation Gate two-cycle self-review

## Outcome

`partial` — the bounded relation implementation and Composite regression have
no remaining blocker. The mandatory clean all-six-family Evidence Harness run
remains unproven and is visible in the result rather than waived.

## Cycle 1 — coarse defect extraction

### Potential blockers

1. **The first canary did not point at an existing option ID.** The secondary
   option had no ID, so the mutation set an empty attribute. This did not meet
   the wrong-existing-target requirement. The final canary adds a temporary
   Target-local `carrier-option-secondary` ID, preserves the exact mutated
   source, and still false-passes under the pre-change Core.
2. **The parent verifier treated a successful Composite script as failed.**
   The child retained native exit `1` from its final intentional negative.
   The parent now trusts child exceptions plus the generated Gate summary, not
   stale `LASTEXITCODE`.
3. **The complete Evidence Harness did not pass.** Three attempts stop at the
   same Diagnostic Review positive. An isolated capture proves the two paths
   are `query-filter` focus outline color/style, and a direct same-Edge control
   passes. No threshold, retry rule, or comparison behavior was weakened.

The first two blockers are resolved. The third sets the Gate result to
`partial`.

### Potential non-blockers

- The wrong-target probe resolves an unkeyed option to `unresolved`; because
  the Reference resolves to `entity-option-primary`, the relation fails. The
  Gate does not claim that two unresolved options are equivalent.
- The duplicate-identity negative reports once per state in addition to the
  active relation mismatch. Repetition is raw evidence, not a new diagnostic-
  presentation project.
- The Target state snapshot uses the exact Reference scenario block injected
  only into a temporary copy. The product Target remains harness-free.

### Evidence weaknesses

- A naturally semantic, unannotated active option was not invented for this
  Gate. The code reuses that resolver path, but the positive uses the existing
  explicit identity.
- Real assistive technology behavior is not tested.
- Full current regression is not clean because of the unrelated focus state.

### Claim overreach

The result must not say that every ARIA relation now compares logical meaning,
that every active option can be inferred without identity, that Entity
Selector design is canonical, or that all current Gates pass.

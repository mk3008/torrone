# Cold-start / Portability Gate result

## Attainment

`portable-after-minimal-externalization`

The Baseline packet was not sufficient for every proof boundary. Fresh Agent A
produced a mechanically correct but systematically renamed Consumer stylesheet,
and Fresh Agent B reproduced a coherent Date range model that did not match the
human-approved completion responsibility. Two small knowledge supplements were
added only after those failures. Different Fresh Agents, different business
fixtures, and the unchanged CLI/Core then reproduced both missing boundaries.

This is evidence that the method is not dependent on this conversation's long
history for the tested common-shell/search and calibrated DatePicker families.
It is not a claim of portability to every UI family, framework, browser, or
project, and it does not create a public package.

## Fresh-context isolation

Four separate worker agents were started with fresh context and explicit input
allowlists. Each owned only one test directory:

| Run | Fresh context | Responsibility | Prior-agent result visible |
| --- | --- | --- | --- |
| A | Fresh Agent A | Baseline search/shell authoring and transfer | no |
| B | Fresh Agent B | Baseline Human Calibration replay | no |
| C | Fresh Agent C | source-independence retest after Iteration 1 | no |
| D | Fresh Agent D | calibration-boundary retest after Iteration 2 | no |

The agents shared the repository filesystem, so this was not an operating-
system read sandbox. Isolation was enforced through fresh model context, exact
allowed-file prompts, separate write boundaries, and no mid-run hints. Reports
and sources contain no oracle or forbidden-history dependency. Agent B's
material disagreement with the hidden oracle is additional evidence that the
answer was not leaked. The conclusion is therefore process-isolated rather
than cryptographically hermetic.

## Test A: Fresh Reference authoring

Agent A selected the accepted common-shell/search responsibilities and created
a supplier-onboarding queue plus an equipment-inspection Target. The Reference
remained fixed-data, buildless, and free of network/data/application layers.
Conformance passed 25 states; the snapshot contained 28 identities, 12
scenarios, and zero bounded accessibility issues. Target comparison passed
with zero errors and diagnostics. An isolated risk-color negative failed with
24 occurrences of one exact signature, and the unmutated after-control passed.

Independent business review found and prompted an autonomous correction for a
collapsed-navigation Grid defect that comparison had reproduced in both sides.
This shows why browser comparison alone is not design approval.

Test A nevertheless failed the Gate's source-independence proof. Reference and
Target CSS each contained 295 declarations; 147 property names and 142
normalized property/value pairs occupied the same positions. Hashes, class
tokens, and local IDs differed, but source inspection showed systematic
renaming. No Target or CLI repair was used to relabel this as success.

## Test B: Human Calibration replay

Agent B received only the Baseline resources, pre-calibration drafts, verbatim
feedback, and fixed fixtures. Its Single date behavior, validation, valid open
boundaries, opposing selected/unavailable treatments, scenarios, negatives,
and independent maintenance-history Target were strong. Single Conformance
passed 28 states, Date range Conformance passed 48, Target comparison passed,
six targeted negatives failed, and all runtime/a11y observations were clean.

The hidden-oracle evaluation was `partial`. The replay used one combined range
input, popup Start/End phases, and an explicit Apply action. The approved model
uses two directly labeled boundaries where one click completes the active
boundary and closes the calendar. The replay also invented a surrounding
Continue action. The CLI correctly proved transfer of the Agent's different
model; it could not prove human approval.

## Knowledge elevation classification

This is protocol Test C: the current-agent evaluator classified Agent B's
proposals only after the replay ended. Fresh Agent C below is separately named
for the Iteration 1 retest and did not receive this oracle evaluation.

### Correctly generalized

- activation, meaningful partial state, completion, validation, focus, and
  opposing visual states must form one coherent operation story;
- correction knowledge belongs in executable scenarios, negatives, and
  self-review rather than duplicate expected-value prose;
- fixture cues such as a displayed current date must agree with the configured
  fixture.

### Correctly kept local

The Agents kept exact colors, dimensions, date cutoff, weekend colors, input
format, clear/icon Tab behavior, optional boundary policy, Today action, and
specific field layout out of long-lived requirements.

### Over-generalized

No DatePicker product choice was promoted to long-lived knowledge. Agent B's
Apply workflow was a local invention, not a promoted rule.

### Under-generalized in the Baseline

- renamed source is not proof of independent Consumer implementation;
- a reviewer's suggested alternative is not automatically the accepted design;
- the smallest correction should resolve the observation without inventing
  new modes, completion actions, or surrounding workflow;
- unresolved product-coherent alternatives must stay unresolved even when
  Conformance and comparison pass.

## Failure causes and iterations

| Baseline failure | Primary cause | Minimal addition | Fresh retest |
| --- | --- | --- | --- |
| systematic CSS renaming accepted as independent | authoring-boundary insufficiency, then Agent self-review error | 10 lines / 583 bytes | Agent C, different renewal queues: pass |
| Apply/phase model differed from approved calibration | Human Calibration protocol insufficiency, Agent error, and feedback ambiguity | 10 lines / 518 bytes | Agent D, different maintenance/compliance fixtures: pass by responsibility |

Agent C used a one-file Grid/direct-listener Reference and a split-file
Flex/`@layer`/delegated-class Target. Conformance passed 23 states, comparison
passed with zero diagnostics, and a primary-action color negative failed with
23 occurrences of one signature. Source organization was independently
structured rather than renamed.

Agent D used two directly operable boundary inputs, one-click active-boundary
completion and close, valid Start-only/End-only states, no Apply/Continue/Today
workflow, distinct selected/range/unavailable treatments, and an independently
structured vendor-insurance Target. Single and Range Conformance passed 12 and
18 states, Target comparison passed, and the completion negative failed only
the three completed states. It also explicitly left alternative field models,
navigation scope, redundant-button Tab order, and product boundary policy
unresolved. This matches the human-approved operation responsibility without
claiming that the feedback selected every local implementation choice.

The replay was not a complete visual clone of the hidden approved artifact.
In particular, D did not reproduce its month/year navigation or every inline
field affordance. The feedback described those as optional or comparative
examples, while the central range correction was explicit. The attainment is
therefore for the important operation and observation responsibilities, not for
every local control choice in the final oracle.

## Scope of portability

The evidence supports a future author using a short authority, one cross-PoC
knowledge note, a small number of accepted References, and the current CLI/Core
to author and transfer already calibrated operation families. It does not show
that an external adopter can select the correct Reference from a large catalog
without curation, create a new family without first-time Human Calibration, or
run outside this repository/toolchain without packaging work.

No new human design decision is required for this Gate. Consumer Identity
Interference can proceed as the next bounded phase. Profile freeze, public
packaging, CLI API freeze, new canonical UI, and MCP remain out of scope.

# Customer search — Run 3

Standalone static HTML specimen for the supplied common shell and customer-search task.

Open `index.html` in a browser. The URL accepts `?drawer=open|hidden&theme=light|dark`; omitted or invalid values resolve to `drawer=open` and `theme=light`. The Header controls toggle the Drawer and theme for the current page only. Search and pagination are intentionally non-persistent static controls.

# Run 2 — Customer search

Local-only static customer-search sample using the supplied shared shell and the frozen design manifest.

Open `index.html` directly. Optional query parameters set the initial shell state:

- `?drawer=open|hidden`
- `?theme=light|dark`

The header controls toggle the Drawer and theme for the current page session. Search, Clear, collection add, record links, and pagination are present as static sample controls; they do not persist data, navigate, or connect to a service.

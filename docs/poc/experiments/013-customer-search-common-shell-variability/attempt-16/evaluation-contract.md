# Purpose

Test whether the Manifest's shell and pane ownership contracts produce a
shell-wide Header, overflow-safe bounded conditions, and a fluid result Grid
inside a fixed composition fixture. The unchanged product prompt and frozen
Manifest snapshot are the only screen-generation inputs. Generate all three
runs once without individual replacement or repair.

# Outcome boundary

The experiment is complete when all three sources are generated once, then
captured and evaluated as they are. A failed visual result remains evidence; it
must not be individually regenerated or edited. Changes to the Manifest,
prompt, or fixture require a later numbered attempt with three new runs.

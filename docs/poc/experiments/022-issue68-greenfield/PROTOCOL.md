# Frozen protocol
- One run per arm. Same gpt-5.6-sol low reasoning, Windows Chromium, fixture and vanilla target. Storybook is a development tool and may author stories during its own run. No prior target code or existing stories.
- Freeze the supplied control, exact script and prior results. Keep them outside receiver directories. The candidate transport adapter supplies candidate files at the old routes. Primary strict run uses byte-identical oracle; a separate continuation runner executes unchanged original steps/assertions and logs outcomes after failures.
- The common brief includes legitimate target dimensions that determine normal fit, but contains no evaluation scripts, viewport test values or expected vectors. Full Torrone uses the catalog and relevant Skills; there is no matching approved executable Reference in the current repository. Storybook uses official beta CLI and Skills, and may build stories/tests from scratch. Prompt Only uses the common prompt and general tools.
- Each condition gets one normal build/self-check opportunity before first scoring, with equal opportunity to repair a startup/build error. Then one round of feedback consisting of scenario ID and observed/expected failure text from its own run. No cross-arm or source oracle sharing. Preserve first and final submissions separately.
- Per-check statuses are pass/fail/not-evaluated. Pass rates use all 15 existing cases as denominator, with missing cases listed. No added expectations. Categories: PC fit/overflow/restore (5); mobile fit/overflow/restore (7); scroll selection (1); filled width (1); document switch/reflow (1). Visual hierarchy and selected vs focused appearance are separately reviewed against catalog and reported descriptively, outside oracle scoring.
- Award ★ to all exact ties on comparable integer outcomes. Use a 5% tie band for time and token measures. Missing or non-comparable telemetry is N/A; use no aggregate win count. First/final pass totals are headline aggregates.
- Log input/output/cached tokens as emitted, elapsed seconds for setup, sessions, own checks and oracle evaluation, authored support artifacts, retry rounds, human interventions and unresolved issues. Credit and currency totals are unknown absent actual billing data. Historical authoring time and shared setup not independently measured are excluded from numeric measured totals and labeled.
- Quality checklist on final output: runtime starts; no third-party runtime dependency; fixture-driven responsive state rather than test-case hardcoding; readable separation of layout/state/event responsibilities; runnable authored self-test; no observed failure in scoped keyboard/chooser/close paths reviewed separately. Record pass/fail/unverified with evidence and no fictitious human approval. Source LOC and tested story count are descriptive.

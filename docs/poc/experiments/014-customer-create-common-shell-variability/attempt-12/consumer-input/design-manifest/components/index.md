# Components

- [Header](header.md) - Identify the shared workspace and host an available Drawer controller or global control.
- [Drawer](drawer.md) - Separate available navigation from the workspace and Header controller.
- [Page header](page-header.md) - Identify the current task or destination without duplicating global navigation.
- [Environment notice](environment-notice.md) - Distinguish a consequential product environment without using a decorative watermark.
- [Breadcrumb](breadcrumb.md) - Show a supplied page hierarchy without pretending to be visit history.
- [Record fields](record-fields.md) - Preserve field meaning across read-only, create, and edit tasks.
- [Search conditions](search-conditions.md) - Bound a query task and its primary and clearing actions.
- [Result grid](result-grid.md) - Support scanning a result set without owning its data meaning.
- [Result card](result-card.md) - Support identity-oriented, heterogeneous record summaries.
- [Pagination](pagination.md) - Continue a declared result set without inventing its count or page state.
- [Status badge](status-badge.md) - Express a short record state without relying on color alone.
- [Dialog](dialog.md) - Contain one bounded blocking task without becoming a second screen.
- [Confirmation](confirmation.md) - Name a consequential action and its supplied consequence with a safe alternative.
- [Step indicator](step-indicator.md) - Orient a user within a stable linear multi-step task.
- [Dashboard panel](dashboard-panel.md) - Present one decision-oriented metric, queue, or trend.

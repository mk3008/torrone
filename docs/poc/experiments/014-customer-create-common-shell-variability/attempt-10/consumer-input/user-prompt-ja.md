# Fixed user prompt

既存の共通シェルを再利用して、顧客追加の静的HTMLを作成してください。

- 画面名は `顧客追加`、説明は `新しい顧客情報を登録します。` とします。
- 顧客IDは内部管理用の連番であり、画面に入力欄を表示しません。
- 入力項目は氏名、生年月日、住所、電話番号、メールアドレス、備考です。氏名、生年月日、住所、電話番号、メールアドレスは必須、備考は任意です。
- 画面内で必須入力、日付形式、電話番号形式、メールアドレス形式を検証します。各エラーは対象の入力欄と結び付けて表示します。
- 保存操作は表示しますが、保存、データ接続、画面遷移、権限判定は実装しません。
- 画像は表示しません。
